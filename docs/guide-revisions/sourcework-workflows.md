# Sourcework: evidence-first reporting workflow (review draft)

**Status:** Draft pending in-app verification.

## Organize a project

Create a project for a clearly defined reporting question, not merely a dumping ground for files. Name it so another reporter can distinguish it from related work. Add or reference relevant sources through the existing [**Source Library**](/sourcework?tab=sources) and project workspace. Before uploading, verify permission to use or retain sensitive recordings and avoid adding material unrelated to the work.

A source is the underlying recording or document. A transcript is a derived representation. An excerpt is a selected passage. The distinction matters: derived text must not silently replace the original when facts, attribution or exact wording are important.

## Transcribe and verify

1. Add a recording or source using the supported workspace controls, preserving sufficient context to know who, what and when it represents.
2. Review the resulting transcript alongside the original wherever the quotation, name, number or sequence is consequential.
3. Correct or annotate doubtful passages using the workspace's available editing mechanisms; do not convert uncertain transcription into a confident attributed quotation.
4. Create excerpts only with enough surrounding context to preserve meaning. When moving a passage into a story or production script, return to the source for final confirmation.
5. Distinguish errors introduced by transcription from contradictions in the source itself.

## Find and reuse material

Search across projects and the Source Library to locate likely sources, then open the underlying result and verify its provenance. Search ranking and semantic similarity indicate relevance, not truth or permission to publish. When adding an existing source to another project, link to the same underlying asset where the tool allows rather than creating avoidable duplicates.

## Editorial checks

Before publishing from an excerpt, verify exact words, speaker identification, dates, context, potential edits and the original audio or document. AI-assisted summarization is an aid to retrieval; it is not an independent source.

**Review before publication:** Verify screen labels and permission rules; cross-link starting a project, transcripts/excerpts, source referencing, source-library browsing and search. Do not invent retention, confidentiality or consent rules not yet adopted by WUWF.
